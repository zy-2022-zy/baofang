📋 端口分配工具流程

  1. 报备人员从“📦 我的批次 → 批次列表”多选批次 → 导出 Excel
  2. 报备人员在下载的 Excel 中填充“端口预占位”列
  3. 上传填好的 Excel → 工具按规则拆行 → 预览拆行结果
  4. 确认无误后，点“回传完整子端口” → 原行变为“占位行”，新建行存实际子端口，状态→“报备中”
