# 样本收集清单（需求管理系统 · Phase 0）

> 目的：在出 PRD / 数据模型 / 流程图之前，先把"现实"摸清。这份清单是真真要给我的素材，按优先级排列，**能给我多少就给多少**。

---

## 🔴 最高优先级（先给我这些就能开干）

### 1. 真实的"需求收集表" 1-2 份
你现在用的"需求收集表"长什么样？
- **Excel 共享表**（最理想）：直接发我文件 / 截图 / 复制粘贴几行
- **飞书表格**：导出成 Excel 或截图
- **企微文档**：截图

我需要看到的：
- 列头（字段名）
- 几行真实数据（不同业务线各 1-2 行）
- 哪一列是"必填"、哪一列是"选填"——你心里有数就行，不用表格里标

### 2. 真实的"驳回记录" 3-5 条
你们处理方（D 角色）日常维护的驳回表长什么样？
- 字段：签名、运营商、端口、驳回原因、日期……
- 至少 3-5 条真实记录

### 3. 真实的"业务线叫法"
我之前列的 8 条业务线：
> 实名 / 引流 / 引流支撑 / 免白 / 视频短信 / 5G 消息 / 三方报备 / 三方免白

**这个分类对吗？** 你们内部实际怎么叫？有没有合并的、拆分的、漏掉的？

## 🟡 次优先级（有就更好，没有也能继续）

### 4. 真实的"提单"消息原文
客服/战略客户/资源采购**实际在群里发过**的需求消息，3-5 条原文（截图 / 复制粘贴都行）。

我需要看他们**用什么方式**、**什么格式**、**什么语气**提单。

### 5. 真实的"拆行"案例
有没有一次提单，要被处理方拆成多个子需求的真实案例？
- 比如"这个签名要报 3 个运营商"
- 或者"这个端口要分 5 个区域"
- 或者"这个免白要分 3 个实名企业"

### 6. 真实的"报备结果回填" Excel
