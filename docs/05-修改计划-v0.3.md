## 完整子端口合法值

- ① 纯数字字符串（如 `12345678`）
- ② 文本"无尾号要求（申请新通道）"
- ③ 文本"有尾号要求（手填任意数字字符串）"

数据库存用户输入的**原始字符串**（不规范化），前端用一个 input + placeholder 提示三种填法。

## 新表 business_config

```sql
CREATE TABLE business_config (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    config_type TEXT NOT NULL,    -- 'category' 或 'sub_category'
    value       TEXT NOT NULL,    -- '55' / '77' / '1' / '2' / '4' ...
    sort_order  INTEGER DEFAULT 0,
    enabled     BOOLEAN DEFAULT 1,
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(config_type, value)
);

-- 种子数据
INSERT INTO business_config (config_type, value, sort_order) VALUES
    ('category',     '55', 1),
    ('category',     '77', 2),
    ('sub_category', '1',  1),
    ('sub_category', '2',  2),
    ('sub_category', '4',  3);
```

## 新增 API

| Method | Path | 用途 |
|--------|------|------|
| GET | /api/business-config | 拉所有配置（前端表单下拉） |
| POST | /api/business-config | admin 新增（type+value） |
| PATCH | /api/business-config/:id | admin 启/停 |
| DELETE | /api/business-config/:id | admin 删除 |
| GET | /api/batches 增强 | JOIN user → 加 submitter_name |

admin 鉴权：只允许 user.role = 'E_admin' 调用增删改。
